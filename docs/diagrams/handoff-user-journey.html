Auto-handoff: one pin per terminal

The wrapper (tmux via claude-auto, or an AgentsRoom tab) owns a terminal ID that outlives every /clear. Each save pins its handoff to that ID, so the cleared session resumes exactly what its own terminal saved. Without a wrapper, you type /clear and resume yourself; everything else is the same.
