Does your AI get dumber mid-conversation?

It does — and not because it ran out of room. Long before the window is full, quality starts sliding.

Reasoning quality degrades and reasoning cost rises as the context window fills — in practice somewhere around 120,000–140,000 tokens of occupancy, regardless of how cheaply those tokens were served. Cache reads are billed at a discount but occupy the window at full size, so they count in full.

This kit measures that occupancy out-of-band, and past a per-model threshold tells the agent to write a structured handoff and stop. The next session finds it, announces it, and picks up where you left off.

How it works

01

A watcher measures, the model never guesses

A lifecycle hook reads the session's own transcript and computes what the next API call will actually carry. The model is never asked how full its context is — it cannot see its own token count, and asked directly it will produce a confident, plausible, wrong number.

02

Past the threshold, one instruction fires

Cross an absolute per-model threshold and the watcher injects a single instruction to invoke the handoff skill. The skill finishes the action in flight, writes a dense document — objective, current state, decisions and why, files touched, next steps, gotchas — and stops. It fires at most once per session.

03

The next session already knows

Session start scans for untransferred handoffs, announces them with a one-line description each, offers a choice when several are open, and marks the chosen one transferred on actual resume. Resuming never requires you to remember that there was something to resume.

Why it's built this way

Deterministic over self-reported

Usage figures are computed by serving infrastructure and returned in metadata the model never sees. All measurement here is a subprocess reading files. No component ever asks the model to estimate its own context usage.

Occupancy, not billing

The unit is what the next call will carry: fresh input, cache writes, cache reads at full size, and the previous output. Cumulative session totals are a billing concept — summing them double-counts every re-send of the history.

Inform, don't hijack

Session start announces and offers a choice; it does not seize the session. Open with an unrelated task and parked handoffs get one sentence while your task proceeds. Auto-resume exists, and is off by default.

Fail open

The watcher and announcer exit 0 on any internal error. A broken hook must never block a session. Memory- and search-based channels degrade honestly — the skill never claims a handoff was saved somewhere it wasn't.

Known limitations

  • Codex hooks are experimental: the flag name and the accepted hooks.json shape have varied across versions, and Windows support has lagged.
  • Cowork hook execution is best-effort. Treat the skill layer as the reliable one there.
  • The extension couples to claude.ai's DOM and internal API shapes, which change without notice. It is built to fail silently rather than interfere.
  • Token estimation for pending content is ±20%-class and deliberately early-biased.
  • Claude Code and Codex occupancy measures differ slightly in composition, so identical numbers are not identical semantics — normalize with per-model entries.
  • Codex PostToolUse injection sacrifices one tool result, by design.
